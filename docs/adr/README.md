## Changes in revision 39
- **ADR 0022 Decisions 4 and 5 and invariant I2 amended** (docs only; Phase 2 gate P2-G at `bee9d97`, major M1 and condition C1; decision log "PHASE 2 GATE (P2-G...)" and "DECISION REVERSAL (BL-134)"): the revision 34 sentence that the bundle's pricing catalogs and test profiles "are inserted when their key is absent" contradicted the repair rule of revision 38 and is superseded. Decision 4 now states the rule: when the bundle's run is stored, absent members of the seven deletable kinds (test profile, pricing catalog, persona, rubric, evaluator, metric definition, metric binding) that the stored run lists are not inserted again unless `repair_members=True`, which writes no audit row; a run that is not stored is a new import; direct `store_snapshot` and `store_definition` calls still insert a deleted record they name (documented limit, batch G ambiguity B1). Decision 5: a rescoring stores only the rows whose IDs are not yet stored and is subject to the same rule. Invariant I2 cites `test_storing_the_same_bundle_again_does_not_bring_back_a_deleted_member` and `test_repair_members_inserts_the_deleted_member_again`. Rejected: a new invariant I7 (the policy-rule test of ADR 0022 pins six invariants with I6 as the self-check; the repair rule belongs with the rescoring invariant); leaving the old sentence with a pointer (an Accepted ADR would keep stating a privacy-relevant rule the code no longer follows).
- **ADR 0020 Decision 6 amended** (docs only; gate minor m2, batch D ambiguity A18): `deleted_at` is the Python process's UTC clock read just before the audit row is inserted, the last statement before the commit; the earlier text "the commit time of the deletion, from the store's clock" is superseded. Rejected: changing the code to the database clock (a behaviour change after the gate, for no gain in what the row proves). `test_deletion_audit_counts_per_kind_exact` pins only that the value is a UTC instant inside the call, so the source of the clock is a documented fact, not a pinned one.
- The machine-read parts keep their format: ADR 0022 keeps 13 numbered rules and invariants I1 to I6; no row was added to or removed from ADR 0019 Tables 1, 2, 3 or 5 or ADR 0020 Decision 3 and its `counts` table.
