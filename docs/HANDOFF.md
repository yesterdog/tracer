## 1. What this project is
An Apache-2.0, bring-your-own-keys (BYOK) framework for evaluating **AI voice agents** built on Pipecat-style stacks (Dograh, VoicEra and others). Focus: Indian languages plus English. The caller may be a human (post-call analytics on real recordings) or a simulator. The framework runs no models itself; all STT/TTS/LLM calls use the user's keys.

Scope rules from the project owner:
- Only the AI agent is evaluated. There is **no IVR and no human hand-over concept**. Speaker roles are exactly `caller`, `agent`, `unknown`.
- Languages (configured): English, Hindi, Marathi, Telugu, Tamil, Kannada, Malayalam, Punjabi (Gurmukhi), Gujarati. Native script only (no transliteration). No code-mix in 0.0.1. Provider-reported tags are always accepted and recorded.
- Money is **USD only** in 0.0.1.
- Core rule: **consume telemetry if present, never break if absent.** Missing inputs make a metric `not_applicable` and a missing cost `not_available`, never 0 or false. Never extrapolate or assume.
- Quality over effort: no cut lists. If a task slips, the date moves, not the bar.

Product shape (from the approved plan): MVP-1 is for builders (offline scoring of recordings plus simulated test calls). MVP-2 is for researchers (benchmark suites, statistics). Phase 1, the current phase, is the schema package `tracer-evalschema`.

## 3. Key decisions (all made by the project owner)
- **Names:** distribution `tracer-evalschema`, import `tracer_evalschema`, release `0.0.1`. JSON Schema `$id` is a URN: `urn:tracer:evalschema:0.0.1:<entity>` (no domain owned). PyPI availability of the name was not reserved.
- **IDs:** UUIDv7, stored natively; wire form is a type-prefixed string (`run_<uuid>`) in JSON and logs; per-type patterns; bare UUIDs are mapped via `from_external()`.
- **Verdict:** headline "x/y required checks passed" (y includes not-applicable); status pass / fail / inconclusive; weighted score always carries `weight_coverage`.
- **Pass rules:** only `range{min?,max?,inclusive}`, `equals_true`, `one_of` (no bare `threshold`). A per-turn metric stores its share in a separate `per_turn` summary (counts, share, turn coverage); `value` is empty for it.
- **Versioning:** same id + integer version, immutable. Files from a newer schema version are rejected (`SchemaVersionTooNew`); exact version match while `0.0.x`.
- **PII:** snapshots hold a reference + plain SHA-256-JCS digest of the test profile, never PII. Shared exports and sealed payloads drop or key (HMAC) the digest; `hmac-sha256-jcs/v1` is registered; reserved field is `key_ref`. The snapshot digest excludes the profile digest. Evaluator instructions use `{{profile.*}}` placeholders with a lint.
- **Human-subject data:** a derived marker (true for human callers, `unknown` roles, or no role evidence); a stored marker may be stricter than derived, never looser; precautionary markers are re-derived at export time; `consent=not_obtained` or `unknown` blocks benchmark exports.
- **Cost:** `basis` is only `reported` or `computed`; no `estimated`. Computed cost needs known usage of the billable event and a known price including billing rules. Black-box agent costs are `not_available`. Non-USD reported costs and costs with no currency are `not_available` with the raw value kept. Reported currency labels `usd`/` USD ` are normalised with a warning; `$` is never mapped.
