# Phase 2 batch D: mutants of the scratch oracle

Method: a runner applies ONE text edit to a pristine copy of the oracle source (migrate.py, versioning.py, deletion.py, errors.py, engine.py, tables.py, __init__.py, migrations/env.py, migrations/helpers.py, migrations/versions/0001_initial_schema.py), runs the batch D test files and the batch A scaffold file (SQLite side, Python 3.14, stop at the first failure) or, for the mutants that only Postgres can see, the matching tests with -m postgres against a throwaway Postgres 18.6 (-k selection), restores the pristine files and reads the failures. Four worker copies of the oracle ran in parallel. The tests of the run are the final ones.
