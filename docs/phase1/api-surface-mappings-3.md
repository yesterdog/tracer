## 2. `voicera_transcript.map_f8(text, *, created_at, privacy, declared_language=None) -> MappingResult`

`text` is the whole file decoded as UTF-8 (`str`); anything else (bytes, a list, a path, `None`) is a caller error and raises `TypeError` (P, M13). The converter never opens a file and has no file-name parameter. `created_at` and `privacy` are as in batch 6; `declared_language` is a `LanguageDeclaration` document or `None` (N14). A declaration the model refuses (a script subtag, a source other than `user_declared`, an `@` in `declared_by`, a language outside the nine, a missing field) is a bad caller argument and raises the model's own `ValidationError` (P, M12); it is never repaired and never dropped with a warning (note for dev: `Recorder.commit` drops an optional field that fails validation, which must not happen to the declaration; validate it first). A bad `privacy` or `created_at` raises likewise. Content never raises.

### 2.1 Lines and pointers (P)

Lines are numbered 1-based by splitting at LF only; one trailing CR is removed from each line; the empty piece after a closing LF is not a line; one leading U+FEFF is dropped from line 1 (M11). U+2028, U+2029, NEL, VT, FF, FS, GS, RS and a lone CR inside a message are characters of its text, not line ends (so `str.splitlines()` is wrong here). Source pointers (also the form of `IngestWarning.path`, ADR 0012 Decision on `path`): `f8:<n>` is the whole line n; `f8:1/call_id` is the text after `call_id=`; `f8:<n>/timestamp`, `f8:<n>/speaker` and `f8:<n>/text` are the parts of message line n. A warning's `raw` is the source value as sent (a lone surrogate shown as U+FFFD, N82).

### 2.2 The structure read

- **Header** (line 1): `call_id=<value>` with a non-empty value, taken to the end of the line verbatim (no trimming). Value not shaped like a bare UUID (8-4-4-4-12 hex digits, either case, no braces): kept, with warning `call_id_not_uuid` (path `f8:1/call_id`, raw the value) (M6). A line 1 that is not a header: warning `header_not_recognized` (path `f8:1`, raw the line); if line 1 is a message line it is also mapped as a message (M10).
- **Delimiter** (line 2): exactly `---` (no trailing space), consumed (`consumed` holds `f8:2`). Otherwise warning `delimiter_not_found` (path `f8:2`, raw the line); a line 2 that is a message is also mapped.
- **Message line**: `[<timestamp>] <speaker>: <text>` with exactly one space after `]`, a speaker label without white space or colon, the first colon after the label, then either end of line or exactly one space followed by the text. The text is the rest of the line byte for byte (further colons, brackets, leading or trailing white space, Unicode spaces and joiners included). Empty text (`user:` or `user: `) is a message with text `""` (M7).
- **Other non-blank lines** (a continuation, a second `---`, `user:hello` without the space, no brackets): warning `unparsed_line` (path `f8:<n>`, raw the line). They are never appended to a previous turn and never become a turn (M5). Blank lines (white space only) are skipped without a warning. A file with no non-blank line: no records and one warning `empty_input` (no path, no raw).
- **Speaker** `assistant` -> role `agent`, `user` -> role `caller`, case-sensitive. Any other label (`system`, `Assistant`): no Turn, warning `unknown_enum_value` (path `f8:<n>/speaker`, raw the label) (M4). The role `unknown` is not produced.

### 2.3 Records

- One **Transcript**: `source = agent_export`; `provider_call_ref = ExternalRef(system="voicera", kind="call_id", value=<the id verbatim>)` when line 1 is a header (M8); `declared_language` exactly as supplied, else absent; `privacy` as supplied. Nothing else: no `provider`, no `model`, no `detected_language`, no `detected_language_raw`, no `language_confidence`, no `timeline_origin`. Made when there is at least one Turn or a recognised header, else none.
- One **Turn** per message line with a known speaker, in file order, never sorted (timestamps may repeat or decrease), `seq` 0-based over the turns made (no gap for a skipped line): `role` as above; `source = agent_log`; `timing_source = none`; `text` verbatim (a lone surrogate becomes U+FFFD with `text_not_valid_unicode`, path `f8:<n>/text`, raw the replaced text, derivation `lone_surrogate_replaced`); `wall_time = {at, meaning: "unknown"}` when the timestamp parses. Absent: `start_ms`, `end_ms`, `segments`, `language`, `language_raw`, `interrupted` (never false), `exchange_index`. Text is never normalised, stripped or cleaned (M17).
- Nothing else: no Exchange, StageSpan, UsageRecord, Artifact, ChannelMap, ToolCallEvent, CostRecord, Run. Nothing about how the call ended is stored or inferred (the closing message is an ordinary agent turn). `MappingResult.gaps` is empty (the static register carries F8's rows).
- `external_refs` holds the same `ExternalRef` as `provider_call_ref`; `external_ref_sources == ("f8:1/call_id",)`.

### 2.4 Timestamps (P)

Read as an extended ISO-8601 instant: `YYYY-MM-DD`, `T` or one space, `hh:mm:ss`, an optional fraction of any length, then `Z` or `+hh:mm` / `-hh:mm` (M1). Converted to UTC with six fractional digits (derivation `iso_offset_to_utc_us`); an offset other than `+00:00` is converted without a warning (M3); more than six fractional digits are cut and `time_precision_reduced` is warned (path `f8:<n>/timestamp`, raw the timestamp as sent). No zone: no `wall_time` and `naive_timestamp`. Not an instant (text, empty, basic format `20261024T...`, an impossible date or offset, a bare number): no `wall_time` and `timestamp_not_parseable`. The Turn and its text are mapped in every case (M2). A timestamp is never turned into `start_ms` or `end_ms`, not even from the difference of two.

### 2.5 The declaration (N14, ADR 0004 Decision 6g)

Stored on the Transcript only, as supplied, never copied into an observed field. It has no trace entry (it is the caller's argument, not source data); its table row has kind `user_declared`. Turns, trace and warnings are the same with and without it.

### 2.6 What the evaluation does with the result (ADR 0004 Decisions 6f and 6h)

The mapping makes the input kind `agent_transcript` available (M9). With it and no audio, no timing and no reference: p95 latency (`language_independent`, `requires turn_timing`) is `missing_input`; an agent turn count is applicable; goal completion (judge, `mr`, `hi`, `en`, not script-sensitive) is `language_not_observed` (declared: scored, `language_source = declared`, this transcript's ID; with only `hi`, `en`: `unsupported_language`, `declared`); WER (`requires agent_audio, reference_text`) is `missing_input`; a script-sensitive check on agent turns is `language_not_observed` with or without the declaration; the mixed scripts cause no `unsupported_script`. Tests: `test_f8_untagged_transcript_language_reasons`, `test_f8_declared_language_reasons`.

## 4. Warning codes (closed; `_support_b14.WARNING_CODES_F8`)

`empty_input header_not_recognized call_id_not_uuid delimiter_not_found unparsed_line unknown_enum_value timestamp_not_parseable naive_timestamp time_precision_reduced text_not_valid_unicode`. A warning's `message` is a fixed sentence under 200 characters that quotes no text of the input and no source line of 12 or more characters (only `path` and `raw` carry source values, by contract; `MIN_QUOTED_LINE = 12` lets a sentence name the format, for example `call_id=`). The twin gives no warning.

## 6. The private fixture and the n-gram check (what CI can and cannot do)

- **Location and policy.** The real file lives only under `packages/evalschema/tests/fixtures/private/voicera/` (git-ignored, guarded). The tests that read it carry `@pytest.mark.private_fixtures`; the project configuration deselects that marker (`addopts = ... -m 'not private_fixtures and not local_only'`), so CI deselects them (does not skip them). Run locally with `uv run pytest -m private_fixtures packages/evalschema/tests/test_mapping_f8.py`. With no file under `private/voicera/` each of them skips with the message "no real file under tests/fixtures/private/voicera/ (expected in CI)" (M16); a skip is NOT a pass and the owner's run must show passes, not skips. Each file found is a parameter (`file-0`, `file-1`, ...; names are never used as ids).
- **The four local-only tests.** `test_f8_real_file_maps_without_fabrication` (structure, counts, field presence, record validity, the no-fabrication check), `test_f8_real_file_converter_is_silent` (stdout, stderr, file descriptors 1 and 2, logging at any level, Python warnings: counts only; no warning message quotes a line), `test_f8_twin_matches_real_structure` (the content-free signature: BOM, line endings, final newline, header and id shape and case, delimiter, timestamp shape including the zone, separators, labels, no blank and no unparsed line; reports the names of differing features), `test_no_private_text_in_committable_files` (below).
- **No text in any message.** The local-only tests call `_support_b14` functions whose failure keys hold names, indices and counts; they fail with `pytest.fail(..., pytrace=False)` (no traceback value, no assertion introspection) and wrap the converter call so an exception reports only its class. CI proves the first part: `test_f8_structural_checks_leak_no_file_text` feeds deliberately broken results against a file full of sentinel words and asserts that no failure key contains a sentinel word, the call id or a date; `test_f8_private_tests_interpolate_only_names_indices_and_counts` is an AST guard that every f-string field in the four tests and their two loaders is on an allow-list of indices, counts, type names and failure-key lists; `test_f8_private_tests_carry_the_marker_and_are_deselected_by_default` and `test_f8_private_tests_skip_only_when_no_file_is_present` guard the marker and the skip. The safeguard that the converter never logs, prints or echoes content runs in CI on the twin and on hostile input (`test_f8_converter_never_prints_logs_or_echoes_content`, six inputs) and locally on the real file.
- **The n-gram check, `test_no_private_text_in_committable_files`.** When the real file exists, the word 8-grams of its message texts (the header, delimiter, timestamps and labels are excluded; windows span lines; words are NFC, case-folded, edge punctuation and zero-width characters removed, JSON `\uXXXX` escapes decoded) are computed in memory. Every committable file (`git ls-files -co --exclude-standard`: tracked, or untracked and not ignored; nothing under `fixtures/private/`; the twin, this test file and the docs included) is scanned for them. The output is the number of grams, the number of files skipped (binary or over 20 MB) and `path (count)` pairs. CI cannot run it, because CI never has the file. **The twin's non-derivation therefore rests on its construction from the documented structure only and on reviewer attention**, plus this local check by the owner (run it after placing the file and after every change to a committed text file). CI-side the scanner is tested on planted text (plain, upper-cased with other punctuation, split over lines, JSON-escaped, with joiners inside words, one word changed, a 7-word excerpt that must not match, a binary file that must be skipped) and `test_f8_scanner_reaches_the_twin_and_no_other_file_shares_its_8_grams` shows it reaches the repository and that no other committable file shares an 8-gram with the twin.
- **Limits, stated plainly.** Lines shorter than 8 words are not protected (a short user turn can be quoted unseen). Paraphrase, translation and transliteration are not found. A copy that changes a word in every 8-word window is not found. Binary files and files over 20 MB are not scanned. The file name of the real file is not text-scanned. The check protects against pasting; it is not a proof of independence.

## 9. Ambiguities and recommendations (auto-approvable)

- **M1** Timestamp separator: `T` or one space. ISO 8601 says `T`; RFC 3339 allows a space; Python parses both. Pinned: both. Recommend accept (a rejected space would drop every wall_time of a space-separated file; nothing is guessed either way). If the real file uses neither, the local-only run reports it (wall_time absent, warnings counted).
- **M2** A naive, unparseable or impossible timestamp: no `wall_time`, a warning, the Turn kept. Recommend accept (the text is the evidence; a guessed zone would be a fabricated instant).
- **M3** An offset other than `+00:00` is converted to UTC without a warning (the documentation says UTC, but a stated offset is unambiguous). Recommend accept.
- **M4** An unknown speaker label (`system`, `tool`, a capitalised form) makes no Turn and warns `unknown_enum_value`, as F4 does for an unknown role. The alternative (a Turn with role `unknown`) keeps the text but states a speech act the source does not describe. Recommend accept; the owner may prefer keeping the text if the real file ever has such a label (the local-only run will say).
- **M5** A non-blank line that is not a message is never appended to the previous turn: the format says one line per message, so a continuation line is a deviation and appending would be a guess. The text is lost from the mapping but quoted in the warning (`raw`). Recommend accept. If the real file turns out to wrap long messages, the format description in ADR 0018 is wrong and needs an amendment.
- **M6** A call id that is not a bare UUID is kept verbatim and warned. Recommend accept.
- **M7** An empty message text is a Turn with `""`; blank lines are skipped silently. Recommend accept.
- **M8** The `ExternalRef` system is the constant `voicera` (the platform name is the user's statement, ADR 0018 Decision 6, unverified), kind `call_id`. Alternative: a caller-supplied platform name. Recommend accept the constant until the Phase 6 importer verifies the export; note the hygiene conflict of section 7.
- **M9** The mapping makes `agent_transcript` available (as the existing worked-example test of ADR 0004 6f does), not `transcript`. Recommend accept; the choice belongs to the Run, not to this converter, and the language results do not depend on it.
- **M10** When line 1 or line 2 is a message line (a truncated export), it is still mapped as a message and the missing header or delimiter is warned. Recommend accept (nothing is thrown away).
- **M11** One leading U+FEFF before `call_id` is ignored without a warning, CRLF endings are accepted and the CR is not text. Recommend accept (encoding artefacts, not content).
- **M12** An invalid declaration raises `ValidationError` instead of becoming a warning. Recommend accept (it is the caller's act, N14; silently dropping it would give `language_not_observed` and hide the error).
- **M13** Non-text input raises `TypeError`. Recommend accept.
- **M14** No Exchange is built: a per-line timestamp of unknown meaning marks no boundary, and ADR 0011 forbids inventing them. Recommend accept.
- **M15** Shingle size 8 words and the 12-character warning-quote threshold are qa's choices (the task named 8-word shingles). Recommend accept; a shorter window (6) would catch more short quotes at the price of false positives on common phrases.
- **M16** The local-only tests skip, rather than fail, when no real file is present. Recommend accept, with the owner's run required to show passes (a green `-m private_fixtures` run with only skips is not evidence).
- **M17** Text is never normalised, stripped or cleaned; NFC and NFD are preserved. Recommend accept (VerbatimText).
- **M18** `.gitattributes` has no entry for the twin: on a Windows checkout with `autocrlf`, the twin would get CRLF endings and its recorded sha256 and the structure comparison with the real file would change. Recommend adding `packages/evalschema/tests/fixtures/synthetic/voicera-twin-*/** text eol=lf` (lead's call; I did not touch `.gitattributes`).

## 10. Validation and its limits

- **Red:** with no converter, the test file is red for the right reasons: `ModuleNotFoundError: No module named 'tests.support.mappings.voicera_transcript'` for the tests that call it, `AssertionError: ... is not written yet` for the hygiene test, `F8:<key> is not registered` for the eight gap rows. The fixture tests and the checker, scanner and guard self-tests pass today. Logs under `docs/phase1/evidence/red/batch22-f8/` for Python 3.11 to 3.14.
- **Oracle-green:** a throwaway oracle converter (qa scratch area, outside the repository, about 210 lines on the shared `Recorder`) plus the eight gap rows makes every default test pass on 3.11 to 3.14 (135 passed). The oracle and the tests share one author: this shows the tests are satisfiable and the readings consistent, not that the readings are right.
- **Mutants:** 47 hand-made mutants of the oracle (role swap, meaning `start`, a language tag, an `agent_stt` source, `interrupted=False`, strip, NFC, naive-as-UTC, dropped precision warning, unknown speaker kept, seq counts lines, call-id lower-casing, missing external ref, declaration copied to `detected_language` or ignored or not validated or traced, a print, a message quoting the line, `splitlines`, BOM and CR handling, delimiter not consumed, empty text dropped, de-duplication, sorting by timestamp, truncating the concatenated line, a raise on NUL, bytes accepted, missing warnings, basic-format timestamps accepted, surrogate not replaced, untraced `seq`, missing and bogus table rows, an Exchange built, a wall_time shifted as if from the file name, runtime logging, a file-descriptor write, a Python warning, a stripped bidi control) were each killed; none survived.
- **Local-only tests were run only against stand-in files** (invented English text with the documented structure, in scratch copies of the repository): they pass on a conforming file and fail with feature names only for CRLF, a blank line, an unknown label, a missing zone; the n-gram test fails with only a path and a count when a stand-in sentence is planted in a document. Nothing was run against the real file, which was never opened.
- **Not verified:** that the real export has the structure described (the T separator, one space after `]` and after the colon, no continuation lines, no blank lines, LF endings, UTF-8 without BOM, no other speaker labels); that the twin shares no text with the real call (only the owner's local run can show it, and only for 8-word windows); that the export is VoicEra's standard one; the Marathi of the twin (`needs_native_review`).
