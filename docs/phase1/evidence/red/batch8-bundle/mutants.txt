# Batch 7 (P1-14 bundle and export) mutants (qa, 2026-10-23)

Throwaway oracle `oracle15` outside the repository: the repository src of 2026-10-23 (batch 5 implemented) plus the P1-14 code written to docs/phase1/api-surface-bundle.md: `bundle.py` (RunBundle, ExportBundle, WithheldRecord, PayloadRedaction, ProvenanceRedaction, check_run_bundle, check_export_bundle, check_observed_tier, evidence_tier, the seam keyword `require_resolved`), `privacy.export_human_subject`, `loader.load_bundle`, `errors.UnresolvedReferenceError` and `BundleSizeError`. One change per mutant (the oracle file is patched in place in a private copy and restored). Each mutant is run over `test_bundle.py`, `test_export_rules.py`, `test_bundle_tier.py` and `test_bundle_adversarial.py` (346 tests) on Python 3.13.15 with `-x`; CAUGHT = a test failed (the first is listed), SURVIVED = none failed. Final run on the final tests, four parallel workers.

Final run: 228 mutants, 224 caught, 4 survived, 0 broken patches. The mutants cover: the evidence-tier fields (T), every rule of the run bundle (R), every rule of the export bundle (E), the models, constants and messages (M: closed sets, frozen, hiding, value leaks in messages), the seam keyword and the typed errors (S), the loader (L), `export_human_subject` (P), and, for each loop over records, the variant "only the first record is checked" (F).

## Survivors

- R53 | the cost summary check is skipped when any cost record is declared withheld | SURVIVED | not pinned on purpose (contract B17): the ADR does not say what a summary check does when a record it names is withheld; the oracle skips the check, the tests neither require nor forbid it.
- R54 | the exchange-index checks of `check_transcript` are not skipped when an exchange is declared withheld | SURVIVED | not pinned on purpose (B17), same reason.
- R55 | the persona embedded in the snapshot is not offered to the seam | SURVIVED | equivalent in the oracle: `ConfigSnapshot` validates its persona reference itself (batch 3), so the seam finds nothing more.
- E43 | tool-call consent needs "some" instead of "all" of the run's consent markers | SURVIVED | equivalent in the oracle: a human-subject artifact or transcript whose consent is not obtained is rejected on its own record before the tool-call rule runs, so "all" adds nothing. The contract (4.2) states the rule as "at least one marker with consent obtained and none without".
