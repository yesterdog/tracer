# Batch 3 mutants (qa, 2026-10-23)

Throwaway oracle outside the repository: a correct implementation of api-surface section 22 on top of the real batch 1 and 2 code. One change per mutant; each mutant is run with `pytest -x` over the 241 batch 3 test files (`test_privacy`, `test_artifact`, `test_transcript`, `test_events`, `test_results`, `test_results_language`, `test_verdict`, `test_snapshot`, `test_run`, `test_dataset`, `test_batch3_entities`) on Python 3.13, with `test_policy_documents_free_text_lint_limitation` deselected (P1-20a). CAUGHT = at least one test failed (the first failing test is listed); SURVIVED = all passed. A mutant whose patch did not apply or whose module did not import is reported separately (none in the final run).

Final run: 470 mutants, 442 caught, 28 survived. Every survivor is explained below: equivalent given another rule of the oracle, or a reading the tests deliberately do not pin (api-surface 22.3).
