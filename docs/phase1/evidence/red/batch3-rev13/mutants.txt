# Batch 3 revision 13 mutants (qa, 2026-10-23)

Throwaway oracle `oracle11` outside the repository: a correct implementation of api-surface section 22 at revision 13 (rev 11 to 13 decisions N20 to N27, O1 to O9, N41, N42, D1 to D3), built on the real batch 1 and 2 code. One change per mutant (a few use two coordinated edits, marked as a list in the harness). Each mutant is run with `pytest -x` over the WHOLE test tree (`packages/evalschema/tests`, 862 tests) on Python 3.13, with the six tests that are red for every implementation deselected (`test_policy_documents_free_text_lint_limitation`, `test_policy_documents_low_entropy_digest_limitation`, the three gate-bound `test_ids.py` tests and `test_versioned_entity_set_matches_adr`). CAUGHT = at least one test failed (the first failing test is listed); SURVIVED = all passed.

Final run: 174 mutants, 167 caught, 7 survived. The first pass had 15 survivors; eight were closed by strengthening the new tests (listed below) and the final run above was repeated after those edits.

## Rerun of the 470 batch 3 mutants (`../batch3/mutants.txt`) against the new test tree

The same 470 mutants (as patched into the revision 13 oracle, whole test tree, six red-for-everyone tests deselected): 445 caught, 25 not caught. Three of the 25 patches no longer applied because the oracle code they patch changed (T52, E27, E33); re-expressed for the revision 13 code (`TRANSCRIPT privacy optional`, `ingest code is free text`, `tool source accepts the transcript sources`) all three are caught. One (S32, `pricing ref: digest optional`) no longer applies because the field is `content_digest`; its re-expression is E16 above (caught). The 21 that still survive are exactly the survivors already explained in `../batch3/mutants.txt` (A12, U04, U09, U17, U18, R72, R73, L06, L11, L21, L74, S01, S08, S17, S18, S24, S25, S26, S27, S28, S37; equivalent in the oracle or a reading the tests deliberately do not pin). Seven former survivors are now caught. Five because of the new tests: A32 (empty `ChannelMap.channels`, item 7), U15 (fragment, item 16), L29 (no turn and no transcript, item 5), L56 and L57 (`agent_channel_unknown` only when `agent_audio` alone is missing, item 4). Two by existing tests, because the revision 13 oracle code differs from the batch 3 oracle there: U16 (relative URI, now caught by `test_endpoint_url_syntax_rules`) and E34 (`test_every_id_reference_field_has_registered_prefix`). No mutant that was caught before is uncaught now, so the edits to existing tests did not weaken them.
